The Reality Behind the Code
ROS (Rana Operating System) is the brainchild of Rana Halder, a developer whose journey is defined by raw passion and relentless struggle. While operating systems are typically built on powerful computers and multi-monitor setups, Rana did not have access to a PC or laptop due to severe financial hardships. Building this OS on a smartphone wasn't an experimental choice made for novelty—it was the only option he had.
Driven by an intense desire to create something from scratch, Rana spent countless days and sleepless nights glued to a small mobile screen, typing thousands of lines of low-level code. He poured his heart and soul into this project to prove that lack of resources cannot stop a true engineering mindset.
The Survival Setup
Armed with nothing but an Android smartphone and an unbreakable will, Rana orchestrated the entire bare-metal development environment using mobile applications:
Termux: As the core Linux terminal.
Acode: As the primary code editor for writing C and x86 Assembly.
Clang & NASM: For cross-compiling the freestanding C kernel and assembling the bootloader.
QEMU (qemu-system-x86_64): To emulate the x86 hardware architecture directly on a mobile device.
Conquering Extreme Complexities
Building an OS is notoriously difficult, but doing it on a mobile device without standard debugging tools introduced brutal challenges. Rana successfully debugged and conquered them all:
Breaking the Sector Limit: When the OS outgrew its memory limits and crashed, Rana successfully diagnosed and rewrote the Assembly bootloader to break past the classic 15-sector reading limit, forcing the system to load a much larger kernel payload into memory.
Fixing Mobile Input Bugs at the Kernel Level: He encountered bizarre bugs where the mobile keyboard injected invisible spaces into the OS terminal. To fix this, Rana engineered a custom, smart strcmp and strncmp logic inside the bare-metal C kernel to dynamically parse and sanitize mobile keystrokes.
No Standard Libraries: Every single feature—from clearing the screen, manipulating VGA memory (0xb8000), styling text colors via Attribute Bytes, to calculating the exact padding for centered ASCII logos—was written purely in freestanding C, without the luxury of <stdio.h>.
Direct Hardware Reboot: Rana successfully programmed the OS to directly communicate with the hardware, sending specific hexadecimal signals (0xFE) to the keyboard controller's I/O port (0x64) to execute a hard-reset reboot command.
The Philosophy
The creation of ROS proves that true engineering is not bound by wealth, expensive laptops, or high-end hardware. It is driven by logic, patience, and an unyielding spirit. Rana's achievement is a testament to what a developer can accomplish when sheer passion overcomes poverty.
